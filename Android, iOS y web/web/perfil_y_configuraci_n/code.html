Privacidad y Almacenamiento Local

Protección integral de datos comerciales

1. Soberanía de Datos Locales: Kiosquito almacena el catálogo de productos, inventario en estantes y el cuaderno de deudas (*fiao*) prioritariamente en el almacenamiento seguro de tu dispositivo. Puedes operar tu caja sin conexión a internet y el sistema sincronizará los cambios automáticamente al detectar red.

2. Dualidad Monetaria: Las conversiones entre Dólares Estadounidenses (USD) y Bolívares (VES) son de referencia interna para el cobro ágil. Kiosquito no interviene ni procesa transacciones bancarias directas, operando como software de gestión y punto de venta independiente.

3. Respaldo Cifrado: Cada cierre de caja y reporte mensual se cifra punto a punto para garantizar que únicamente el dueño registrado tenga visibilidad de los balances financieros de la Bodega San Antonio.
